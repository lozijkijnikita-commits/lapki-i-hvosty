Лапки и Хвосты — учебный проект

Файлы:
- index.html — структура сайта и JavaScript
- style.css — оформление сайта

Как запустить:
1. Распакуй папку проекта.
2. Открой index.html в браузере.
3. Чтобы редактировать код, открой папку в Visual Studio Code.
Важно: index.html и style.css должны лежать в одной папке.
Каталог и корзина демонстрационные; оплата не подключена.
